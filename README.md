# Trabajo Final Juan Bautista Xifro

Repositorio del Trabajo Final de Ingeniería en Sistemas de Información (UAI, 2026): evaluación comparativa de modelos de lenguaje para atención al cliente.

## Estructura publicada

- `proyecto/src/`: código de carga del corpus, acceso a modelos y cálculo de costos.
- `proyecto/notebooks/`: experimento reproducible de la primera iteración.
- `proyecto/data/`: muestra del corpus traducida al español.
- `proyecto/tests/`: pruebas unitarias.
- `proyecto/requirements.txt`: dependencias necesarias.
- `proyecto/TF_Juan_Bautista_Xifro_2026.docx`: única versión vigente del Trabajo Final.

Los materiales internos de gestión y contexto de desarrollo se conservan únicamente de manera local y no forman parte del repositorio publicado.

Las instrucciones de instalación y ejecución están en [`proyecto/README.md`](proyecto/README.md).

Los archivos locales `proyecto/venv/` y `proyecto/.env` no se versionan: el entorno se recrea desde `proyecto/requirements.txt` y las credenciales nunca deben subirse.
